## 0. 设计原则（UI 层）

1. **Project-centered**：有当前项目时，主工作区在项目壳内；无项目时先选/建项目。  
2. **一条创造流可读**：意图对齐 → 协作 → 项目任务 → 验证部署 → 资产沉淀 — 不是扁平工具箱。  
3. **不覆盖 Intent OS**：质押创建、工作台判断、确认部署、治理、权益、Credit 仍可达。  
4. **诚实边界**：sim / MVP 能力用文案标明；不假装图谱库、真钱市场、FreeCAD 已接。  
5. **i18n**：zh / en 完整切换；**禁止中英混排**（专有名词除外：Credit、InnoForge、Lumen 等）。  
6. **无独立任务产品**：顶栏/侧栏不得出现与项目平级的「任务空间」。

```
┌─────────────┬──────────────────────────────────────────────┐
│ Brand       │  [Project switcher ▾]  Scenario pills        │
│ InnoForge   │  Stage chip (if in project)     Credit · 中/EN│
│ tagline     ├──────────────────────────────────────────────┤
│             │                                              │
│ GLOBAL      │           MAIN (context-dependent)           │
│ · 项目      │                                              │
│ · 我的任务  │                                              │
│ · 空间      │                                              │
│ · 发现      │                                              │
│ · 市场      │                                              │
│ ─────────   │                                              │
│ ACCOUNT     │                                              │
│ · 总览      │                                              │
│ · 权益      │                                              │
│ · 治理      │                                              │
│ · 历史      │                                              │
│ · 账号      │                                              │
│ · 连接      │                                              │
└─────────────┴──────────────────────────────────────────────┘
```

- **左侧**：全局入口（不随项目 Tab 变）。  
- **顶栏**：当前 **Project** 切换器 + 场景模式 +（项目内）阶段摘要 + Credit + 语言。  
- **主区**：由全局页或「项目内 Tab」决定。

### 1.2 全局导航（产品语义）

| 入口 | zh | en | 行为 |
|------|----|----|------|
| 项目 | 项目 | Projects | 项目列表 / 创建；点进某项目 → 进入 **项目壳** |
| 我的任务 | 我的任务 | My tasks | **只读过滤视图**（§4） |
| 空间 | 空间 | Spaces | 资产/权限（§3） |
| 发现 | 发现 | Discover | 可加入项目 / 生命体目录 |
| 市场 | 市场 | Marketplace | Credit 门控组件；非任务板 |
| 总览 | 总览 | Overview | Credit、声誉、进行中项目摘要 |
| 权益 / 治理 / 历史 / 账号 / 连接 | （保留 Intent OS） | Equity / Governance / History / Account / Connections | 经济治理闭环 |

**禁止出现的全局项：**

- ❌「任务」/「任务执行」作为与「项目」平级的主入口（暗示任务空间）  
- ❌「任务空间」文案  
- ❌ 把 Personal/Team/Project 画成三个任务看板

### 1.3 默认落地

| 条件 | 默认屏 |
|------|--------|
| 有最近项目 | 进入该项目 → **意图树** Tab |
| 无项目 | **项目**列表（空态引导创建） |
| 深链「我的任务」 | 打开视图；点任务 → 跳回所属项目任务 Tab 并选中 |

## 2. 项目壳（Project chrome）

进入任一 Project 后，主区顶部增加 **项目内子导航（Tab）**，侧栏「项目」保持高亮或显示当前项目名。

### 2.1 项目内 Tab 模型

| Tab | zh | en | 主内容 |
|-----|----|----|--------|
| **意图** | 意图树 | Intent tree | **主舞台**（默认） |
| **任务** | 项目任务 | Project tasks | 本项目 Task tree（§2.3） |
| **协作** | 协作 | Collaborative | 阶段机 + 多代理条 + 协商 |
| **工作台** | 工作台 | Workbench | 意图卡 · 孪生 · 变体判断 · Lumen |
| **验证** | 验证部署 | Validate & deploy | 确认 · 部署 · 反馈 · 生命体入口 |
| **项目资产** | 项目资产 | Project assets | 本项目空间内临时资产（也可从「空间」进项目切片） |

创建意图 / 质押：作为 **项目列表上的「新建项目」** 或项目内「编辑主意图」动作，不再需要与项目脱节的孤立顶栏「创建意图」作为唯一路径（可保留快捷入口，但创建结果 = 新 Project）。

### 2.2 意图树 Tab（主舞台）

**布局（线框）：**

```
[ Scenario banner · Plugin hint ]
┌─────────────────────┬──────────────────────┐
│ 树画布（左）         │ 节点详情（右）         │
│ · GOAL / CONSTRAINT │ · 标题 · 状态 · id    │
│ · SUCCESS / BRANCH  │ · 对齐 / 冲突 / 完成  │
│ · 选中高亮           │ · 绑定任务数入口       │
│                     │ · 场景插件 hint 再述   │
└─────────────────────┴──────────────────────┘
[ 添加分支 | 约束 | 成功标准 ]
```

| 状态 | UI |
|------|-----|
| Empty | 「尚无节点 — 从主目标或约束开始」+ CTA |
| Loading | 树骨架屏 |
| Error | 错误码 + 重试；不清空壳层 |
| Conflict | 节点 CONFLICT 态可见；详情提示需人类处理 |

### 2.3 项目任务 Tab（Task tree ∈ Project）

**唯一任务 CRUD 主路径。**

```
[ 筛选：状态 · 执行者 · 绑定节点 ]
[ 新建任务 | 从场景种子生成 ]
┌────────────────────────────────────────────┐
│ 树状或分组列表：                             │
│  · 标题 · 绑定意图节点 · AI|人类 · 状态      │
│  · 推进 / 失败 / 改执行者                   │
└────────────────────────────────────────────┘
```

- 创建时 **默认归属当前项目**；必选或推荐绑定意图节点。  
- 状态机文案：待分配 → 已分配 → 进行中 → 评审 → 完成 | 失败。  
- Empty：「本项目暂无任务 — 从意图分支拆解或使用场景种子」。  
- **不得**在此页提供「切换到个人任务空间」类导航。

### 2.4 协作 Tab

```
[ 场景标签 ]
[ 代理条：研究|设计|仿真|批判|编排 · 在场/待命 ]
[ 阶段轨：草稿 → 探索 → 验证 → 已提交 ]  [ 推进 ]
[ 协商 SSE · 角色代理 · 3D 具身（既有） ]
```

阶段推进需确认（禁用跳级）。G9 裁决 UI 本阶段可只留位，不假装已完成。

### 2.5 工作台 / 验证 Tab

- **工作台**：保留 Intent OS 意图卡、冻结、变体采纳/拒绝、Lumen。  
- **验证部署**：确认 → 部署 → 反馈 → 结算；生命体挂在部署/发现脉络。  
- 顶栏阶段 `Committed` ≠ 已部署：验证 Tab 用部署状态 pill 区分。

## 3. 空间 UI（资产 / 权限 only）

### 3.1 信息架构

全局「空间」进入后用 **分段控件**（非三个任务列）：

| 段 | zh | en | 内容 |
|----|----|----|------|
| 个人 | 个人空间 | Personal | 私有草稿、未发布资产、代理配置；**链到「我的任务」视图**（链，不是内嵌任务板） |
| 团队 | 团队空间 | Team | 共享组件、模板、失败案例、规范 |
| 项目 | 项目空间 | Project | 下拉选当前/某项目 → 项目内临时资产；沉淀 CTA |

每段强调：

- 资产卡片：标题 · 类型 · 来源项目 · 更新时间 · 权限标签（私有/团队/项目）  
- 主 CTA：**沉淀** / **引用到项目**（sim 可 toast + 诚实说明）  
- 页眉说明一句：zh「空间管理资产与权限，任务请在所属项目中处理」/ en 同等语义  

### 3.2 禁止

- 三栏 Kanban 式「个人任务 | 团队任务 | 项目任务」  
- 在空间页创建无项目归属的任务

## 4. 「我的任务」视图

### 4.1 定位

跨项目 **assignment 视图**：`assignee = 当前用户` 且项目未归档。

### 4.2 布局

```
筛选：项目 · 场景 · 状态
┌──────────────────────────────────────────────────┐
│ 任务标题 │ 所属项目 │ 场景 │ 执行者 │ 状态 │ 更新 │
└──────────────────────────────────────────────────┘
行点击 → 打开「项目壳 · 任务 Tab」并选中该任务（深链）
```

| 允许 | 禁止 |
|------|------|
| 按项目/状态过滤 | 在此页「新建任务」（无项目上下文） |
| 快捷「推进状态」（可选，仍写回项目任务） | 复制出第二套任务实体 |
| 空态引导「去项目拆解任务」 | 文案称「个人任务空间」 |

Empty zh：「你还没有被分配的项目任务」· en：「No project tasks assigned to you」。

## 5. 三场景：壳层如何变

场景是 **当前项目属性**（顶栏 pills 可改项目 scenario；列表也可预选）。切换后 **不换 App**，改变：

| 元素 | PRODUCT | RESEARCH | HARDWARE |
|------|---------|----------|----------|
| 顶栏/场景标签 | 产品创新 / Product | 科研 / Research | 硬件 / Hardware |
| 意图树默认种子文案 | 用户问题·增长指标 | 假设·可证伪 | 约束·工艺·BOM |
| 插件 hint | 产品原型（sim） | 文献·假设（sim） | 仿真编排（sim） |
| 项目任务种子 | 原型/测试/指标类 | 文献/实验/分析类 | 仿真/询价/打样类 |
| 协作阶段文案 | 定义→原型→实现→验证 | 假设→设计→实验→分析 | 约束→设计→仿真→打样 |
| 代理条侧重高亮 | 设计·编排 | 研究·批判 | 仿真·编排 |

工作台 / 验证 / Credit 路径三场景共用。

## 6. 关键屏说明 + 文案原则

### 6.1 屏清单（本 UI 阶段）

| 屏 ID | 名称 | 优先级 |
|-------|------|--------|
| G-PROJECTS | 项目列表 / 新建 | P0 |
| P-INTENT | 项目·意图树 | P0 |
| P-TASKS | 项目·任务 | P0 |
| P-COLLAB | 项目·协作 | P0 |
| P-WORKBENCH | 项目·工作台 | P0（保留） |
| P-VALIDATE | 项目·验证部署 | P0（保留） |
| G-MYTASKS | 我的任务视图 | P0 |
| G-SPACES | 空间（三段） | P0 |
| G-DISCOVER / MARKET / OVERVIEW / EQUITY / GOV / HIST / ACCT / CONN | 既有全局 | P1 可达即可 |

### 6.2 通用状态

| 状态 | 模式 |
|------|------|
| Loading | 面板内骨架，保留导航 |
| Empty | 一句说明 + 单一主 CTA |
| Error | `error` 码友好映射 + 重试；403/404 区分 |
| Sim badge | 角落或 hint：「模拟数据 / Sim data」 |

### 6.3 zh / en 原则

- 整壳一种语言；切换立即重渲染 chrome。  
- 用户内容（意图陈述、任务标题）可保留原文，不强制翻译。  
- 专有名词保持：Credit、InnoForge、Lumen、PXN。  
- 废止文案：任务空间、Task space（作为导航名）、个人任务库。

### 6.4 示例文案对

| Key 概念 | zh | en |
|----------|----|----|
| 项目任务 Tab | 项目任务 | Project tasks |
| 我的任务 | 我的任务 | My tasks |
| 空间说明 | 资产与权限边界 | Asset & permission boundary |
| 场景工作区 | 场景工作区 | Scenario workspace |
| 插件入口（sim） | 插件入口（模拟） | Plugin entry (sim) |

### 7.3 新增

- [ ] 全局 **项目列表** + Project switcher  
- [ ] 项目壳 + Tab 子导航（意图 / 任务 / 协作 / 工作台 / 验证 / 项目资产）
