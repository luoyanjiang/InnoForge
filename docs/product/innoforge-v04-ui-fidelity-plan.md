# v0.4 UI 还原度补强

**版本**：v0.5 · 2026-10-23  
**状态**：F1 **已合入（实验壳）** · 产品方案 **已批准** · **[UI 设计 v0.4](./innoforge-ui-design-v04.md) 已完成** · 待 UI 批准后技术设计 + 实现

## 问题（用户反馈）

V1 只加了「意图树导航 / 场景切换 / 协作阶段轨」，界面仍像旧 forge 控制台挂件，**未还原讨论文档的创造操作系统体验**。

F1 补了壳层，但 **产品层跳过**，把任务/空间做成顶层并列，**违背「任务随项目 / 个人任务是视图」**。

## 文档设计意图（必须在 UI 上可读）

相对 [讨论文档 v0.4](./AI创新创造研究系统_讨论文档_v0.4.md) 与 [产品方案](./innoforge-product-方案-v04.md)：

1. **创造流程 OS**：以 **Project** 为容器 — 意图 → 协作 → **项目内任务树** → 验证回流 → 资产沉淀  
2. **意图树为一等主舞台**（项目内）  
3. **三场景可感知差异**（项目属性）  
4. **协作协议可见**：阶段机 + 角色代理 + 关键决策点  
5. **任务树 ∈ 项目**：随项目走；「我的任务」= 跨项目 assignments **视图**  
6. **空间 = 资产/权限边界**（个人/团队/项目），**不是**任务空间  
7. **贡献与激励**：接 G4/G5；不覆盖 Credit

## F1 产品纠错（2026-10-23 · 必须服从）

| 项目 | 说明 |
|------|------|
| **错误** | 侧栏将「任务执行」「资产空间」与项目能力**顶层并列**，读成独立「任务空间」；Spaces 三栏易被当成三套工作区/任务板 |
| **正确** | Task tree **只**存在于 Project；Personal 任务列表是过滤视图；Spaces 只管资产与权限 |
| **后果** | F1 **代码可暂留**，但 **产品叙事与后续 UI 不得延续该 IA**；须先完成产品方案（已写）→ UI 设计 → 再改界面 |
| **本轮** | **不改 UI、不写功能代码** |

权威条文：[产品方案 §2 · §4.2 · §7](./innoforge-product-方案-v04.md)。

## F1 技术设计（已合入 · 实验壳，IA 作废部分见上）

| 字段 | 内容 |
|------|------|
| **状态** | **已合入（实验）** · 产品 IA **部分作废** |
| **问题** | 壳层仍为扁平工具箱；树页过薄；无任务/空间；场景切换几乎不可感；协作无多代理角色条。 |
| **模块** | `forge-console` 壳层 IA · `forge-tasks` · `GET /v1/forge/spaces`（sim）· 既有 tree/scenario/stage |

### IA 映射（F1 当时实现 — 含错误，仅作历史）

| 分组 | 导航项 | 说明 |
|------|--------|------|
| **意图 / 树** | 意图树（默认首页）· 工作台 · 创建意图 | 树为主舞台；工作台/创建保留 Intent OS 闭环 |
| **协作与代理** | 协作 | 阶段机 + 角色条 |
| **任务执行** ❌ | 任务 | **产品错误：任务被抬成顶层并列** |
| **验证部署** | 部署 · 发现 | 保留闭环 |
| **资产空间** ⚠️ | 空间 · 市场 | 空间概念对，但易与任务空间混淆；须在 UI 重设计中澄清 |
| **经济治理** | 权益 · 治理 · 历史 · 账号 · 外部连接 | Credit/声誉/审计可达 |

### 屏与验收

| 屏 | UX | 验收 |
|----|-----|------|
| 侧栏 | 分组标题 + 场景切换条；默认进意图树 | 分组可见；非扁平一长列 |
| 意图树 | 左树画布 / 右节点详情 + 场景插件提示 + 对齐操作 | 同屏编辑；场景切换改标题/插件 hint |
| 任务 | 按意图过滤；列表含节点绑定、执行者、状态；可创建/推进 | 刷新仍在（API） |
| 空间 | 三栏个人/团队/项目 + 沉淀按钮（sim toast/事件） | 可读为资产空间，不假装图谱库 |
| 协作 | 五代理角色条 + V1 阶段轨 + SSE | 角色与阶段同屏 |

### API / 数据

- migration `0009` `forge_tasks`：`id, intent_id, tenant_id, tree_node_id?, title, executor (AI\|HUMAN), status (PENDING\|ASSIGNED\|IN_PROGRESS\|REVIEW\|DONE\|FAILED), created_at, updated_at, created_by`
- `GET/POST /v1/forge/intents/:id/tasks`；`PATCH .../tasks/:tid`（status/executor）
- `GET /v1/forge/spaces` → sim `{ personal, team, project }` 资产占位（无真实对象存储）
- 既有 tree / scenario / collab_stage 不变

### 诚实边界

- 空间资产与任务结果 **不** 接 Neo4j / 对象存储 / 真钱分成  
- 插件入口为文案 hint（产品原型/文献假设/仿真编排），不假装已接 FreeCAD/OpenFOAM  
- Credit 闭环与治理路径必须仍可从「经济治理」组进入

### 风险

- 导航变长 — 分组折叠 + 默认首页=树  
- 勿用新壳覆盖 Intent OS 质押/确认/部署路径
